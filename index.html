Consent Management API for Developers

Add consent lifecycle management to applications and automated workflows using a simple hosted REST API. Create consent, retrieve it, check its current status, and revoke it without building the complete consent lifecycle yourself.

A simple consent lifecycle API

Consent API provides a small set of REST endpoints that applications can call whenever they need to record or verify consent before an action occurs.

Create Consent

Create a consent record for a customer and business scenario.

Retrieve Consent

Retrieve the stored consent record using its consent ID.

Check Consent Status

Determine whether consent is currently ACTIVE, EXPIRED, or REVOKED.

Revoke Consent

Record withdrawal of consent and ensure subsequent status checks return REVOKED.

Where can a Consent API be used?

Consent API can be inserted into workflows where an application needs to record consent and later verify whether that consent remains valid before performing an action or sharing data.

Healthcare

Record patient consent before health information is accessed or shared as part of a healthcare workflow.

Data Sharing

Check consent before customer information is shared with another system or service.

Automated Workflows

Add a consent check before an automated workflow performs a downstream action.

Third-Party Access

Record and verify consent before allowing third-party access to customer data.

Consent API Quickstart

Send a request to create a consent. The API returns a consent ID that can later be used to retrieve the consent, check its status, or revoke it. 

POST https://consent-api-stage1.onrender.com/consents
X-API-Key: YOUR_API_KEY
Content-Type: application/json

{
  "customer_id": "PATIENT-001",
  "application_number": "HOSPITAL-001",
  "scenario_id": "HEALTH-RECORD-ACCESS-001",
  "purpose": "Access patient health records for treatment",
  "expires_at": null,
  "metadata": null
}

The new consent starts in the ACTIVE state. Applications can check its status before continuing a workflow.
